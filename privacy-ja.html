デザインの保存

ネイルの色、柄、パーツ、編集履歴はこのブラウザに保存されます。編集ファイルと画像はダウンロードできます。このサイトの統計コードは、ネイルデザイン、アップロード画像、編集ファイルの内容を送信しません。

任意の訪問統計

訪問統計を許可した場合のみGoogle Analytics 4を読み込み、利用状況を確認します。処理方法や設定に応じて、ページ閲覧、参照元、おおよその地域、端末・ブラウザ情報などが統計として扱われます。Googleのサーバーで処理され、国外で処理される場合があります。

送信データの範囲

統計コードには氏名、メールアドレス、電話番号、デザイン内容を含めません。Google Signalsと広告のパーソナライズ用シグナルは無効です。ページ・参照元URLから検索パラメータとフラグメントを除外して送信します。

Cookieと選択

統計を拒否しても全ての編集機能が使えます。選択はこのブラウザに記憶されます。許可すると分析用Cookieを使用する場合があり、このサイトが設定する有効期間は28日です。サーバーでの保持期間はGoogle Analyticsプロパティの設定とGoogleの方針に従います。

選択を変更する

下のボタンで選択を変更できます。拒否すると以後の統計送信を止め、このサイトから削除できる分析用Cookieを削除します。既に処理されたデータが遡って自動削除されるものではありません。

運営・お問い合わせ

運営：ネイルアートメーカー。公開のGitHub問い合わせページで連絡できます。GitHubへのログインが必要です。公開の場に個人情報を投稿しないでください。

GitHub Issues · Google プライバシーポリシー · Google Analytics opt-out

表示言語

トップページではブラウザの優先言語から韓国語・英語・日本語を選びます。自分で選んだ言語はこのブラウザに記憶されます。IPアドレスで国を調べる外部サービスは使いません。

お問い合わせ・改善のご意見

GitHub Issuesから連絡する

公開の問い合わせページで、不具合、機能の要望、プライバシーや権利に関するお問い合わせを受け付けています。GitHubアカウントでのログインが必要です。非公開のメール窓口ではありません。

不具合を伝えるときは

  • 端末とブラウザ（例：iPhoneとSafari）。
  • 行った操作と、期待していた動作。
  • 実際に起きたこと。共有してよければスクリーンショット。
  • メールアドレス・電話番号・住所・非公開の編集ファイルは投稿しないでください。

保存したデザインについて

デザインはブラウザに保存されます。ブラウザの保存データを削除した場合、JSON編集ファイルがなければ運営者側では復元できません。権利に関するお問い合わせでは対象のページやパーツをお知らせください。非公開の証明資料は公開掲示板に投稿しないでください。

公開ギャラリーでの共有

投稿を選んだ場合のみ、作品画像・ニックネーム・作品名・紹介文・投稿日時をSupabaseに保存し、公開します。画像は縮小してJPEGに変換し、元ファイルをそのまま保存しません。第三者が閲覧・保存できるため、個人情報を含む画像は投稿しないでください。

投稿時にブラウザへ匿名認証情報を保存し、自分の投稿の取り下げに使用します。ブラウザデータの削除や端末の変更で、この操作ができなくなる場合があります。取り下げはギャラリーからの非表示です。保存画像の完全削除は、運営リポジトリのお問い合わせページからご依頼ください。Supabaseの地域設定などにより、国外で処理される場合があります。
