Design storage

Work files, nail colors, patterns, charms and editing history are stored in this browser. You can download work files and images. The site’s statistics code does not send nail designs, uploaded images or work-file content.

Optional visitor statistics

Google Analytics 4 is used to understand site usage only after you allow visitor statistics. Depending on its processing and settings, it measures page views, referral sources, approximate region, and device and browser information. Google processes this data on its servers, which may be outside your country.

Data minimization

The statistics code does not include names, emails, phone numbers or design content. Google Signals and ad personalization signals are disabled. Query parameters and fragments are removed from page and referral URLs before sending them.

Cookies and your choice

You can decline statistics and still use all editing functions. The choice is stored in this browser. When allowed, analytics cookies may be used; this site sets a 28-day cookie expiry. Server-side retention depends on the Google Analytics property settings and Google’s policies.

Change your choice

The button below reopens the choice. Declining stops later statistics and removes analytics cookies accessible to this site. Data already processed is not automatically deleted retroactively.

Operator and contact

Operated as Nail Art Maker. Contact the operator through the public GitHub issue board; GitHub sign-in is required. Do not post personal information publicly.

GitHub Issues · Google Privacy Policy · Google Analytics opt-out

Display language

The entry page selects Korean, English or Japanese using your browser’s preferred languages. A language you choose yourself is saved in this browser. No separate IP geolocation service is used.

Contact & feedback

Send feedback through GitHub Issues

Use the public issue board for bugs, feature requests, privacy questions and rights inquiries. A GitHub account and sign-in are required. This is a public board, not a private mailbox.

For a useful bug report

  • Device and browser, for example iPhone and Safari.
  • The steps you took and what you expected to happen.
  • What actually happened, with a screenshot only if you are comfortable sharing it.
  • Do not post your email, phone number, address or private work files.

About saved work

Work is stored in your browser. The operator cannot recover a design after you clear browser storage unless you kept a JSON work file. For a rights inquiry, identify the relevant page or charm; do not publish private supporting documents on the public board.

Public gallery sharing

Only when you choose to post, we store the design image, nickname, title, description and posting time with Supabase and display them publicly. Images are resized and converted to JPEG; the original file is not stored unchanged. Anyone may view or save public posts, so do not upload images containing personal information.

Posting saves anonymous authentication details in this browser so you can remove your own posts. Clearing browser data or changing devices may lose that access. Removing a post hides it from the gallery; contact the operator through the repository contact page if you need the stored image deleted completely. Data may be processed outside your country depending on the Supabase project region and settings.
