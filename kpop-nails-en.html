Choose the mood before the details.

These K-pop-inspired nail ideas use contrast, translucency and a few small accents. They are original combinations for this tool, not recreations of a specific idol’s manicure. The HEX codes are starting palettes for the screen, not real-product shade matches.

01. Milky pink + ivory bows

#F3CFD2#F6EFE6#C98F9C
  1. Set a milky-pink base. Reduce opacity if you want more translucency.
  2. Change one or two nails to ivory to make space between the pink accents.
  3. Add one small bow from Lovely charms; reduce its size until enough base color remains visible.
  4. Keep other nails plain or add a single pearl. Compare the layout before adding more.

02. Nude syrup + burgundy French

#EAD8D2#793341#C7B8B2
  1. Start with a nude base and a jelly finish at a lower opacity.
  2. Choose Curved French and set its color to burgundy.
  3. Use a syrup gradient on a different nail or leave that nail plain.
  4. If you want an accent, add one small metal bow slightly away from the center.

03. Olive + cream winter accents

#65683F#294333#E8E2D2
  1. Split olive and deep green across a few nails. Try satin for a softer finish.
  2. Add Winter tartan to one cream nail and set the pattern color to olive.
  3. Choose a wreath or bow bell as the seasonal accent, then reduce its size.
  4. Leave some nails in solid colors so the check and charm can stand out.

Make two versions and compare.

Save an image, change only one or two colors or charm sizes, and compare again. Keep a JSON work file too if you want to revise it later. The editor offers a set of pattern styles; it does not reproduce every hand-painted detail. This independent tool has no artist or agency affiliation.
