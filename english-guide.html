Create your first set

  1. Shape and length

    Select a nail in the preview. Under Basics, choose a shape and adjust Length. Shape and length apply to the full set of ten nails.

  2. Color and finish

    Set a base color using the color picker, a suggested swatch or a HEX code. Lower Opacity for a sheerer look. Choose a finish. Apply color to all nails copies the base color and opacity; Apply finish to all nails copies the finish.

  3. Layer your designs

    Open Design. A gradient, French tip and pattern can be combined because they are separate groups. Selecting a new effect in the same group replaces that group’s effect. Change the color under each active group or choose Remove to clear it.

  4. Add a charm and adjust it

    Open Charms, choose a category and tap an item. Tap the added charm or its name to open the controls for color, horizontal and vertical position, size and rotation. Sliders help on small screens. Dragging a charm onto another nail moves it there; dropping outside all nails restores its previous position.

  5. Save an image and a work file

    Use Save image to export a PNG. Open Work file → Save work file for an editable JSON file. To continue later, choose Load work file. Importing replaces the current design; Undo can restore the previous one.

  6. Choose your language

    Use the selector above the nail preview to choose 한국어, English or 日本語. Your selection is remembered in this browser, and switching keeps the current design. On the main entry page, a supported browser language is selected automatically; unsupported languages fall back to English. Direct language links keep their specified language.

Saving and restoring work

Autosave is local to this browser and device. Images do not contain editable nail layers. Save a JSON work file before switching devices or clearing browser data. You can copy one nail with Ctrl/Cmd+C and paste onto another with Ctrl/Cmd+V when you are not typing in a field.

About the preview

Use it to plan color and placement, not to predict exact salon results. No hand-photo try-on or text-prompt AI generation is included. A lack of consent for visitor statistics does not block editing.
