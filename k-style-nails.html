K-STYLE NAIL IDEAS

컬러를 덜고,
포인트를 골라보세요.

이 가이드는 맑은 베이스와 작은 장식을 중심으로 K-pop 스타일 무드의 네일을 만드는 세 가지 조합을 제안합니다. 아래 HEX 컬러를 편집기에 넣고 자신의 취향에 맞게 바꿔보세요.

편집기에서 조합하기 ↗

01. 밀키 핑크 + 아이보리 리본

밀키 핑크 #F3CFD2아이보리 #F6EFE6더스티 로즈 #C98F9C
  1. 기본에서 핑크를 넣고 발색 농도를 중간 정도로 낮춰 비교합니다.
  2. 한두 손톱은 아이보리로 바꿔 컬러 사이에 여백을 만듭니다.
  3. 파츠의 러블리 카테고리에서 작은 리본 하나를 고릅니다. 리본을 추가한 뒤 크기 바를 낮춰 손톱의 바탕이 충분히 보이게 합니다.
  4. 다른 손톱은 장식 없이 남기거나 진주 하나만 더합니다. 완성 이미지에서 장식의 비중을 다시 확인합니다.

리본과 진주를 모든 손톱에 같은 크기로 넣기보다, 포인트를 넣는 손톱 수와 위치를 바꿔보세요.

02. 누드 시럽 + 버건디 프렌치

누드 #EAD8D2버건디 #793341뮤트 토프 #C7B8B2
  1. 누드 베이스에 젤리 질감을 고르고 농도를 낮춰봅니다.
  2. 디자인의 프렌치에서 곡선 프렌치를 선택한 뒤 버건디로 바꿉니다.
  3. 다른 손톱은 시럽 그라데이션으로 바꾸거나 바탕만 남깁니다. 프렌치와 그라데이션이 한 세트 안에서 어떻게 보이는지 비교합니다.
  4. 장식이 필요하다면 작은 메탈 리본 하나를 더하고, 위치를 중앙에서 조금 비껴 배치해봅니다.

발색이 너무 강하면 먼저 베이스 농도를 조절하고, 효과 색상도 한 단계 밝게 바꿔보세요. 실제 발색의 재현값이 아니라 화면에서 조합을 찾는 출발점입니다.

03. 올리브 + 크림의 차분한 시즌 네일

올리브 #65683F딥그린 #294333크림 #E8E2D2
  1. 올리브와 딥그린을 몇 개의 손톱에 나눠 넣습니다. 강한 빛 효과를 줄이고 싶다면 새틴 질감부터 비교합니다.
  2. 크림 손톱 하나에 윈터 타탄을 고르고 체크 색상을 올리브 계열로 맞춥니다.
  3. 시즌 파츠는 리스나 리본 벨 중 하나부터 추가합니다. 크기를 줄여 무늬와 파츠가 서로 가리지 않는지 확인합니다.
  4. 전체 손톱에 장식을 채우기보다 솔리드 컬러 손톱을 남겨 대비를 조절합니다.

체크의 선과 크기는 현재 앱에서 제공하는 패턴 표현을 따릅니다. 손으로 그린 체크와 완전히 같은 결과를 보장하지 않습니다.

저장하고 다시 비교하기

첫 시안을 이미지로 저장하고, 파츠 크기나 한두 손톱의 색만 바꾼 두 번째 시안과 비교하세요. 다시 수정하려면 이미지뿐 아니라 ‘작업 파일’의 JSON 파일도 보관해야 합니다.

이 페이지는 직접 조합하는 디자인 제안이며, 특정 네일숍·브랜드와의 제휴나 최신 유행 순위를 의미하지 않습니다.

K-pop에서 영감을 받은 나만의 조합

맑은 시럽 컬러, 리본과 진주, 또는 짙은 컬러와 크롬 포인트로 K-pop 무드의 네일을 구상해 보세요. 특정 아이돌의 실제 네일을 재현하거나 최신 유행 순위를 제공하는 서비스는 아닙니다. 아티스트·소속사와 제휴하지 않은 독립 디자인 도구입니다.
